Para quem vai apresentar.

A apresentação fica com vocês. Este guia reúne as orientações, as teclas e a lista de referências. Para ver a fala pronta de cada cena, use a tecla N durante a apresentação.

01 · Cuidados

O que evitar

01Tratar um traço como lista

Não descrever uma característica física como se fosse característica de todo o grupo.

02Tratar alisamento como culpa

Alisar, trançar ou deixar natural é escolha de cada pessoa. O problema é a pressão.

03Falar de um penteado genérico

Cada povo africano tem os seus. Uma trança significa coisas diferentes em cada cultura.

04Organizar tons de cor em hierarquia

Nenhum tom é o melhor. E cor ou raça do IBGE é autodeclaração, não medição.
